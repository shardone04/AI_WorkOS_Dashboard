# WorkOS AI 회의 전사 샘플

전사 월간 회의. 결제 시스템 QA 병목은 Backend Lead와 QA Manager가 오늘 중 테스트 범위를 P0로 재분류한다. 데이터 파이프라인은 5월 28일까지 Kafka 파티션 전략을 12개 기준으로 확정한다.

공동 경비 Google Sheet는 Finance Keeper가 관리하고 매일 18시에 결산 요약을 공유한다. Gmail Webhook은 Apps Script 배포 URL을 Railway 환경변수에 등록한 뒤 실제 발송 테스트를 진행한다.

Slack 채널에는 주요 결정사항만 공유한다. 다음 회의 전까지 관리자 페이지에서 팀원별 공개 범위를 설정하고, 제출 전 Railway URL 텍스트 파일을 갱신한다.
